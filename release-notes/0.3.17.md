# WilyTrader 0.3.17

## Summary

- Added a primary-panel `P&L` button for completed token positions.
- Kept closed-position P&L visible in the side stats after a trade fully closes.
- Added a closed-trade recap with bought, sold, total hold time, post-fee P&L, return percentage, and sell-leg P&L rows.
- Updated extension metadata to version `0.3.17`.

## Verification

- `node --check extension\src\content.js`
- `node --check extension\src\userscript-wrapper.user.js`
- `node -e "JSON.parse(require('fs').readFileSync('extension/manifest.json','utf8')); console.log('manifest ok')"`
- Packaged `extension\` as `.tmp\wilytrader-0.3.17-extension.zip`

## Release Notes

Existing users of the unpacked Chrome extension need to pull or download the new package, then reload WilyTrader at `chrome://extensions`.

Issue trace: https://github.com/Koprowski/WilyTrader/issues/7
