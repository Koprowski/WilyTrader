# WilyTrader 0.4.5

- Adds a Desktop **Install Update** action that downloads the latest WilyTrader Desktop setup EXE, launches it with Windows installer semantics, then closes the running app.
- Adds an extension **Update Extension Files** action that updates the local unpacked Chrome extension folder from the latest release zip, or runs `git pull --ff-only` when the folder is backed by a repo checkout.
- Opens Chrome Extensions and copies the unpacked extension folder path after extension files are updated, leaving only Chrome's required WilyTrader Reload click.
- Keeps Desktop and Chrome extension release versions aligned at `0.4.5`.
