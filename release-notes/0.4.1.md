# WilyTrader 0.4.1

- Seeds a default `master trading log.xlsx` from the bundled template when a new Desktop install points at an empty captures folder.
- Packages the master trading log template with the Desktop trade-sync resources.
- Applies OHLC SOL and percent workbook formatting by header name instead of fixed column letters.
- Checks Desktop updates automatically at startup and on a six-hour cadence.
- Clarifies extension update guidance so users reload the unpacked extension in Chrome when local files are already current, and only download the zip when they need fresh local files.

## Validation

- `node --check extension\src\content.js`
- `node --check extension\src\background.js`
- `node --check extension\src\userscript-wrapper.user.js`
- `npm --prefix desktop run typecheck`
- `npm --prefix desktop run build`
- `npm --prefix desktop run dist:win`
- `git diff --check`
