# WilyTrader 0.3.14

## Summary

- Fixed settings modals opened from the floating P&L tracker disappearing during background render passes.
- Route and market-cap polling can render while the tracker is visible but the primary trade panel is hidden.
- Modals now close only when the entire WilyTrader overlay is hidden, not when only the primary panel is hidden.

## Verification

- `node --check extension\src\content.js`
- `node -e "JSON.parse(require('fs').readFileSync('extension/manifest.json','utf8')); console.log('manifest ok')"`

## Release Notes

Existing users of the unpacked Chrome extension need to pull or update through Snipalot, then reload WilyTrader at `chrome://extensions`.
