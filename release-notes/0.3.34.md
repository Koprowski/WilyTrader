# WilyTrader 0.3.34

- Fixes Axiom execution chart markers and average entry/exit lines to use the visible execution-time market cap instead of a title-derived or recomputed price.
- Keeps fees separate from chart placement so buy/sell flags stay tied to the captured market cap, not wallet debit, net proceeds, or P&L math.
