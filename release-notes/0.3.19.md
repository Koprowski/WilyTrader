# WilyTrader 0.3.19

- Adds percent-based market-cap exit orders from existing WilyTrader sell buttons.
- Right-click a sell preset to arm a target sell or stop sell for that percentage.
- Draws WilyTrader target/stop lines on Axiom charts with the armed sell percentage and target market cap.
- Triggers armed orders from the live detected Axiom market-cap text, not lagging chart candles.
- Keeps 100% orders tied to the current remaining paper position so scale-in/scale-out workflows use the latest balance.
