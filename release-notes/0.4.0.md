# WilyTrader 0.4.0

- Restores Pulse quick-buy execution on Axiom by using Axiom's native Pulse row navigation while preserving the clicked token context.
- Speeds Pulse auto-buy execution by starting the delay at click time and executing as soon as the Axiom title market cap is available.
- Places Axiom chart execution flags immediately when buys and sells are recorded, with the normal render pass retained as reconciliation.
- Keeps Pulse overlay number labels visible while hiding the yellow quick-buy hit-box fill, border, and glow.
- Tightens Desktop trade-log meta extraction so mechanics and signals such as Pulse buy, momentum, volume, interest, testing, and similar commentary do not become meta names.
- Fixes Last Session Folder Copy/Open actions for archived completed sessions.
- Adds WilyTrader Desktop update notices with release-note and installer-download actions, alongside the existing extension update notice.
- Adds Windows installer packaging for WilyTrader Desktop.
