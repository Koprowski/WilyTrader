# WilyTrader 0.3.3

## Summary

- Applied the primary panel pointer-capture resize pattern to the floating P&L tracker resize handle.
- Tracker resizing now stays active through pointer movement, pointer release, cancel, lost capture, and window blur instead of depending on document-level mouse events.
- Updated extension metadata to version `0.3.3`.

## Verification

- `node --check extension\src\content.js`
- `node -e "JSON.parse(require('fs').readFileSync('extension/manifest.json','utf8')); console.log('manifest ok')"`

## Release Notes

Existing users of the unpacked Chrome extension need to pull or update through Snipalot, then reload WilyTrader at `chrome://extensions`.
