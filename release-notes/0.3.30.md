# WilyTrader 0.3.30

- Places the sell-button right-click target menu to the side of the clicked sell button instead of below it.
- Prefers placing the menu to the left of the button, with right-side fallback when needed.
- Opens submenus left when the parent menu is placed left of the sell button.

## Validation

- `node --check extension\src\content.js`
- `node --check extension\src\userscript-wrapper.user.js`
