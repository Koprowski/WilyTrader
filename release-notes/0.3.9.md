# WilyTrader 0.3.9

## Summary

- Added four visible corner scale handles to the floating P&L tracker.
- Tracker scaling now uses the same opposite-corner anchor model as the primary UI panel.
- Finishing tracker scaling pins the visual position and returns the tracker to a normal top-left transform origin for later dragging.
- Updated extension metadata to version `0.3.9`.

## Verification

- `node --check extension\src\content.js`
- `node -e "JSON.parse(require('fs').readFileSync('extension/manifest.json','utf8')); console.log('manifest ok')"`

## Release Notes

Existing users of the unpacked Chrome extension need to pull or update through Snipalot, then reload WilyTrader at `chrome://extensions`.
