# WilyTrader 0.3.5

## Summary

- Hardened the floating P&L tracker resize flow so releasing the mouse outside the resize corner ends the active resize reliably.
- Removed the tracker content scale cap; the overlay content now scales on both axes from the resized tracker box, with only viewport and minimum box-size limits.
- Changed the left tracker value to match the primary UI paper balance for the active chain.
- Kept the right tracker value explicitly labeled as session P&L.
- Changed the center WILY button into a menu with add paper balance, set paper balance, and reset trading session actions.
- Updated extension metadata to version `0.3.5`.

## Verification

- `node --check extension\src\content.js`
- `node -e "JSON.parse(require('fs').readFileSync('extension/manifest.json','utf8')); console.log('manifest ok')"`

## Release Notes

Existing users of the unpacked Chrome extension need to pull or update through Snipalot, then reload WilyTrader at `chrome://extensions`.
