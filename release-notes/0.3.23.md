# WilyTrader 0.3.23

- Adds targeted diagnostics for the WilyTrader 100% sell-button target/stop menu flow.
- Logs right-click `pointerdown`, `mousedown`, and `contextmenu` handling under `[WilyTrader][exit-target]` in DevTools.
- Logs button classification, market-cap detection, menu rendering, selected target values, order creation, and chart-line moved messages.
- Keeps the bare market-cap shorthand from 0.3.22: `9` means `$9K`, `120` means `$120K`, and four or more digits stay literal.

## Validation

- `node --check extension\src\content.js`
- `node --check extension\src\userscript-wrapper.user.js`
- Direct TypeScript check for `extension\src\axiomChartBridge.ts`
- `npm run typecheck` in `desktop/`

## Debugging

- Open DevTools on the Axiom tab and filter the console for `[WilyTrader][exit-target]`.
- Right-click the WilyTrader 100% sell button and copy the emitted log stages if the menu does not appear.
