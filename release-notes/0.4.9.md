# WilyTrader Release 0.4.9

- Adds visible Desktop update install progress after pressing **Install Update**.
- Streams installer downloads and shows the current stage, percent, and downloaded MB in the Desktop App panel.
- Disables update controls while the installer download/start handoff is in progress.
- Shows clear handoff/failure states if the installer is launched or Windows blocks automatic launch.

Validation:

- `npm --prefix desktop run typecheck`
- `npm --prefix desktop run dist:win`
