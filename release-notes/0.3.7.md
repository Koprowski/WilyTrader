# WilyTrader 0.3.7

## Summary

- Added native Axiom chart markers for individual buy/sell executions.
- Execution markers are keyed by execution id and replayed for the active token summary.
- Added packaged cash-register sound playback for recorded buy/sell executions.
- Updated extension metadata to version `0.3.7`.

## Verification

- `node --check extension\src\content.js`
- `node --check extension\src\userscript-wrapper.user.js`
- `node --check extension\src\background.js`
- `git diff --check`

## Release Notes

Existing users of the unpacked Chrome extension need to pull or update through Snipalot, then reload WilyTrader at `chrome://extensions`.
