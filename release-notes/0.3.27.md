# WilyTrader 0.3.27

- Anchors the 100% right-click target/stop menu to the `100%` sell button instead of the raw cursor position.
- Keeps the menu clamped inside the visible viewport and flips submenus left when there is not enough room on the right.
- Raises the target/stop menu above the WilyTrader panel so it is not obscured by the overlay UI.

## Validation

- `node --check extension\src\content.js`
- `node --check extension\src\userscript-wrapper.user.js`
