# WilyTrader 0.3.15

## Summary

- Aligned Axiom chart labels so average entry labels sit left and average exit labels sit right.
- Added vertical spacing in the floating P&L tracker so the `WilyTrader` word does not overlap the SOL mark lines.
- Constrained the primary panel title and status line to one ellipsized row so trade-status messages do not expand or contract the UI height.
- Updated extension metadata to version `0.3.15`.

## Verification

- `node --check extension\src\content.js`
- `node --check extension\src\userscript-wrapper.user.js`
- `node -e "JSON.parse(require('fs').readFileSync('extension/manifest.json','utf8')); console.log('manifest ok')"`

## Release Notes

Existing users of the unpacked Chrome extension need to pull or update through Snipalot, then reload WilyTrader at `chrome://extensions`.
