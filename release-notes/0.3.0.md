# WilyTrader 0.3.0

## Summary

- Added a floating portfolio/session P&L tracker for supported Padre and Axiom pages.
- Added tracker drag, resize, saved position, saved size, and a settings toggle.
- Preserved token-page-only trading controls while keeping the tracker available on broader supported routes.
- Added panel scaling support and visible panel corner resize handles.
- Added default buy amount persistence and Pulse-to-token-page auto-buy queueing already present in the local feature set.
- Updated docs with a Git-based local refresh command for unpacked-extension installs.

## Verification

- `node --check extension\src\content.js`
- `node -e "JSON.parse(require('fs').readFileSync('extension/manifest.json','utf8')); console.log('manifest ok')"`

## Release Notes

Existing users of the unpacked Chrome extension need to pull or download the updated local files, then reload WilyTrader at `chrome://extensions`. Chrome does not allow an unpacked extension to self-update from the content script.
