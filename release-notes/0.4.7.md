# WilyTrader Release 0.4.7

- Renames the installed Windows product from **WilyTrader Desktop** to **WilyTrader**.
- Sets the installer app id to `com.wilytrader.app`, Start Menu/Desktop shortcut name to `WilyTrader`, and per-machine installs to install under `C:\Program Files\WilyTrader` by default.
- Keeps the packaged layout as Electron expects: app files under `resources\app` and the bundled Chrome extension under `resources\extension`.
- Copies existing settings from the legacy `%APPDATA%\WilyTrader Desktop` folder into the new `%APPDATA%\WilyTrader` folder on first launch when no new settings file exists.
- Bumps Desktop app version to `0.2.1` and Chrome extension version to `0.4.7`.
- Includes compatibility asset aliases for older Desktop builds that still construct release download URLs from the GitHub tag.
