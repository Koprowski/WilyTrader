# WilyTrader 0.3.1

## Summary

- Published the local Pulse quick-buy interception work so Snipalot-managed installs can actually update to it.
- Added a transparent WilyTrader hit layer above Axiom Pulse quick-buy boxes to stop Axiom's native instant-buy handler from receiving those clicks.
- Kept the existing Pulse flow: queue a WilyTrader paper auto-buy at the configured default buy amount, open the token page through Axiom row navigation, then execute after token-page pricing is available.
- Updated extension metadata to version `0.3.1`.

## Verification

- `node --check extension\src\content.js`
- `node -e "JSON.parse(require('fs').readFileSync('extension/manifest.json','utf8')); console.log('manifest ok')"`

## Release Notes

This update must be pulled or installed through Snipalot's WilyTrader updater and then reloaded at `chrome://extensions`. Without the WilyTrader extension update, Axiom receives Pulse quick-buy clicks directly and can show native wallet/funds errors.
