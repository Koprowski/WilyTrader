# WilyTrader 0.4.4

- Clarifies Desktop extension version reporting by separating the running Chrome tab version from the local extension file version.
- Refreshes the detected local extension manifest during update checks so Desktop notices replaced extension files without requiring an app restart.
- Updates extension status messages to say when the running tab is stale and the local files are newer.

## Validation

- `node --check extension\src\content.js`
- `node --check extension\src\background.js`
- `node --check extension\src\userscript-wrapper.user.js`
- `npm --prefix desktop run typecheck`
- `npm --prefix desktop run dist:win`
- `git diff --check`
