# WilyTrader 0.4.2

- Fixes trade-log `ohlc_screenshot` links so each row resolves the screenshot for that trade's own execution or trade time.
- Re-resolves archived screenshot paths by screenshot basename after completed sessions move under `Archive`.
- Uses screenshot metadata and execution IDs before falling back to token-name matching, which prevents repeated same-token trades from reusing the same final session screenshot.
