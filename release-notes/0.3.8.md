# WilyTrader 0.3.8

## Summary

- Changed the floating P&L tracker resize behavior from box resizing to component scaling.
- The tracker now keeps fixed base dimensions and scales the full composed UI, including text, metrics, WILY button, gear, rail, borders, and resize handle.
- Existing saved tracker width/height values are migrated into a saved tracker scale.
- Updated extension metadata to version `0.3.8`.

## Verification

- `node --check extension\src\content.js`
- `node -e "JSON.parse(require('fs').readFileSync('extension/manifest.json','utf8')); console.log('manifest ok')"`

## Release Notes

Existing users of the unpacked Chrome extension need to pull or update through Snipalot, then reload WilyTrader at `chrome://extensions`.
