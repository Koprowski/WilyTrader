# WilyTrader Release 0.4.6

- Restores separate version tracks: Desktop is reset to app version `0.2.0`; the Chrome extension continues on `0.4.6`.
- Updates Desktop release parsing so future Desktop and extension assets can use independent versions instead of inheriting the GitHub release tag.
- Stops treating stale extension heartbeats as current. If no Padre/Axiom content script has checked in recently, Desktop falls back to the local extension manifest instead of showing yesterday's running tab version.
- Uses the Snipalot-style installer handoff: Desktop tries `shell.openPath()` for the downloaded setup EXE first, then falls back to PowerShell `Start-Process` if Windows needs that path.
- Includes compatibility asset aliases for older Desktop builds that still construct release download URLs from the GitHub tag.
