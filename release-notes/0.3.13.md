# WilyTrader 0.3.13

## Summary

- Fixed GitHub issue #5 where the transparent Pulse quick-buy hit layer could intercept clicks intended for settings/filter modals.
- Disabled Pulse hit targets while WilyTrader modals are open.
- Added occlusion detection so Pulse hit targets are not created over Axiom dialogs, modals, popovers, drawers, or large fixed overlays.
- Added a final guard before Pulse auto-buy queueing so stale hit targets refresh instead of trading when a modal now covers the target.

## Verification

- `node --check extension\src\content.js`
- `node -e "JSON.parse(require('fs').readFileSync('extension/manifest.json','utf8')); console.log('manifest ok')"`

## Release Notes

After updating, reload the unpacked WilyTrader extension in `chrome://extensions`. Pulse quick-buy should still work when no modal covers the token row, but modal `Apply` / `Apply All` clicks should no longer trigger Pulse auto-buy.
