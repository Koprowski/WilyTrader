# WilyTrader 0.3.10

## Summary

- Added structured diagnostic logging for floating P&L tracker resize events.
- Logs now capture handle binding, root pointerdown handling, resize start, resize updates, zero-button pointer movement, and resize finish.
- Diagnostic payloads include target/path summaries, corner id, pointer id/buttons, event phase, computed handle styles, tracker rects, anchors, and scale calculations.
- Updated extension metadata to version `0.3.10`.

## Verification

- `node --check extension\src\content.js`
- `node -e "JSON.parse(require('fs').readFileSync('extension/manifest.json','utf8')); console.log('manifest ok')"`

## Release Notes

Existing users of the unpacked Chrome extension need to pull or update through Snipalot, then reload WilyTrader at `chrome://extensions`.
