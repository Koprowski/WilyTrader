# WilyTrader 0.3.12

## Summary

- Fixed delayed executions so buys and sells use the on-screen price after the configured delay instead of applying a random simulated slippage multiplier.
- Renamed slippage labels/log output to max price movement during delay; fees still affect balances and P&L but no longer move entry/exit prices or chart markers.
- Limited Axiom chart artifacts to the current page/session execution window so older ledger entries do not redraw into a fresh chart capture.
- Updated the floating P&L tracker center brand from `WILY` to `WilyTrader`.
- Centered the SOL mark directly under the tracker brand text.
- Updated extension metadata to version `0.3.12`.

## Verification

- `node --check extension\src\content.js`
- `node -e "JSON.parse(require('fs').readFileSync('extension/manifest.json','utf8')); console.log('manifest ok')"`

## Release Notes

Existing users of the unpacked Chrome extension need to pull or update through Snipalot, then reload WilyTrader at `chrome://extensions`.
