# WilyTrader 0.3.18

- Adds WilyTrader Desktop bridge heartbeat support so the desktop app can show the active extension version.
- Sends Chrome tab-captured trade screenshots to WilyTrader Desktop on bridge-synced buy/sell events.
- Updates bridge-facing copy from Snipalot to WilyTrader Desktop while preserving the same localhost endpoint.
- Adds the first WilyTrader Desktop vertical slice for audio-first trade sessions, localhost ledger intake, post-session transcript artifacts, and `trade_log.xlsx` / `trade_log.md` generation.
- Ports the retained Snipalot settings into WilyTrader Desktop: `Ctrl+Alt+T` trade-session hotkey, dependency setup checklist, Gemini CLI Google sign-in/model selection, OpenRouter fallback settings, LLM connection testing, and WilyTrader extension management controls.
