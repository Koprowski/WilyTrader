# WilyTrader 0.3.2

## Summary

- Added a center WILY button action on the floating P&L tracker to reset session P&L by starting a new archived session.
- Clarified the tracker labels: total portfolio remains on the left, and session P&L plus percentage remains on the right.
- Changed tracker resizing so the inner tracker UI scales with the resized outer box instead of clipping the displayed values.
- Preserved the existing panel pointer-resize hardening in `extension/src/content.js`.
- Updated extension metadata to version `0.3.2`.

## Verification

- `node --check extension\src\content.js`
- `node -e "JSON.parse(require('fs').readFileSync('extension/manifest.json','utf8')); console.log('manifest ok')"`

## Release Notes

Existing users of the unpacked Chrome extension need to pull or update through Snipalot, then reload WilyTrader at `chrome://extensions`.
