# WilyTrader 0.3.11

## Summary

- Fixed floating P&L tracker corner resizing based on the `0.3.10` diagnostics.
- The root overlay listener was seeing resize-handle pointer events, but propagation stopped before the tracker-level resize handler started.
- The resize start handler now runs on the root capture layer that receives those events.
- Kept tracker resize diagnostics so the console can confirm `start`, `update`, and `finish` after reload.

## Verification

- `node --check extension\src\content.js`
- `node -e "JSON.parse(require('fs').readFileSync('extension/manifest.json','utf8')); console.log('manifest ok')"`

## Release Notes

Existing users of the unpacked Chrome extension need to pull or update through Snipalot, then reload WilyTrader at `chrome://extensions`.
