# WilyTrader 0.3.6

## Summary

- Added a gear button in the upper-right of the floating P&L tracker.
- The tracker gear opens the existing WilyTrader settings modal.
- Updated extension metadata to version `0.3.6`.

## Verification

- `node --check extension\src\content.js`
- `node -e "JSON.parse(require('fs').readFileSync('extension/manifest.json','utf8')); console.log('manifest ok')"`

## Release Notes

Existing users of the unpacked Chrome extension need to pull or update through Snipalot, then reload WilyTrader at `chrome://extensions`.
