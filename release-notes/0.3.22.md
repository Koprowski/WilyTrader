# WilyTrader 0.3.22

- Handles right-click target menus from the `pointerdown` event as well as `contextmenu`, so the WilyTrader `100%` sell button menu appears even when the browser or page swallows the normal context-menu event.
- Keeps the `100%` target/stop menu scoped to WilyTrader sell-all controls.
- Updates manual market-cap entry parsing so bare values with three digits or fewer are treated as thousands: `9` becomes `$9K`, `120` becomes `$120K`, while four or more digits stay literal.
